# ログイン切れの DM（#1309）

## 一言で

Claude Code のログインが切れてターンが止まったら、owner に **DM が1通** 届く。どのホストのどのスレッドが止まったかと、次の手が書いてある。同じ切れの間に止まったスレッドは、その1通に書き足される。

## なぜ

ログイン切れはスレッドに 🔑 の ❌ embed（#812、[turn-end-notification.md](turn-end-notification.md#claude-code-のログインが切れていたターン-812)）を出すが、それはスレッドを開いた人にしか届かない。直すにはホストで `/login` するしかなく、owner はホストの前にいないことが多い。2026-11-09 は 05:31 に切れ、09:22 に `/login` されるまで約4時間止まっていた。

## あるべき動き

### DM が届くとき

- ターンが #812 のログイン切れ（`… · Please run /login`）で止まったとき。スレッドの 🔑 embed は今までどおり出る（DM はその上乗せ）
- 宛先は `DISCORD_OWNER_ID`。未設定ならアプリの owner（#713。#346 の DM と同じ）

### DM の中身

```
[tachikoma] 🔑 Claude Code のログインが切れました
止まったスレッド（2）:
• https://discord.com/channels/…/…
• https://discord.com/channels/…/…
次の手: ホスト `tachikoma` で `claude auth login`（または `claude` を開いて `/login`）を実行してください。
戻ったら、止まったスレッドでもう一度送ってください（自動では再送しません）。
-# 同じ切れの間に止まったスレッドは、この DM に書き足します（通知は 1 回だけ）。
```

- 先頭の `[…]` はホスト名。2台目のホストが来ても見分けられる。`CLORD_HOST_LABEL` で書き換えられる
- 止まったスレッドは 15 本まで並べ、それより多いと「…ほか N 本」

### 1回の切れにつき1通

- 2本目以降のスレッドが止まっても新しい DM は送らず、1通目を編集してリンクを足す
- **切れが終わる** = どこかのスレッドのターンがエラー無く終わったとき（ログインしていなければ走れないため）。そのあとにまた切れたら、新しい DM が1通届く
- 切れの状態は `~/.c-lord/<instance>/login-alert.json` に残るので、**bot を再起動しても同じ切れの間は DM が増えない**
- 数えるのはインスタンス（bot）ごと。同じホストで別の bot（staging など）が動いていれば、その bot も自分の DM を1通送る

### DM が送れないとき

- owner が DM を閉じている・Discord に届かないとき、スレッドの 🔑 embed はそのまま出て、ログに `WARNING … could not DM owner <id> (<理由>) (#1309)` と `owner DM NOT sent` が出る

## DM からログインし直す（#1310）

ホストの前にいなくても、DM の中でログインし直せる。

### 流れ

1. 切れの DM を送ったら、c-lord は**止まったスレッドとは別の tmux 窓**（`clord-login`。最初に止まったスレッドと同じ tmux セッションに作るので、同じ設定ディレクトリを見る）で `claude auth login` を始める。`/login` と同じ OAuth の流れで、ブラウザは開かない
2. 窓に出たサインインのリンクを取り出して、**同じ DM を編集して載せる**（折り返されたリンクも1本につなぐ）

   ```
   **DM からログインし直す**
   1. このリンクを開いてログイン: <https://claude.com/cai/oauth/authorize?…>
   2. 表示されたコードを、この DM にそのまま返信してください（11:28 まで受け付けます）
   -# リンクが古くなったら 🔄 で出し直せます。
   [🔄 リンクを出し直す]
   ```
3. owner がブラウザでログインし、表示されたコードを DM に返信すると、c-lord はそれを `clord-login` 窓に打ち込み、結果を DM で返す
   - ✅ 成功: DM に「✅ [ホスト] ログインが戻りました」。止まったスレッドそれぞれに「🔑 Claude Code のログインが戻りました。止まっていたメッセージは自動では送り直しません。もう一度送ってください。」。DM 本体は「✅ DM からログインし直しました（HH:MM）」になり、ボタンは消える
   - ❌ 失敗: DM に「❌ [ホスト] ログインできませんでした: <Claude Code の1行>」。🔄 で新しいリンクを出してやり直す

### 守ること

- **コードとして窓に打ち込むのは、owner からの DM の返事だけ。それも窓が待っている間（15分）だけ。** owner 以外の DM には何もしない。待っていないときの owner の DM には「いまはコードを待っていません」と返す。コードの形（空白の無い1語）でない返事には「コードの形ではありません」と返して打ち込まない
- **リンクとコードは DM の外に出さない**（スレッド・チャンネル・Issue・PR・ログ）。ログに残るのは「コードが届いた（N 文字）」だけ
- **勝手に再送しない。** 止まったメッセージを送り直すのは利用者
- 15分たっても返事が無ければ窓を閉じ、DM に「⌛ リンクの受付時間が過ぎた」と出す。🔄 はいつでも押せる（bot を再起動しても押せる）
- ホストでだれかが直接ログインし、どこかのターンが正常に終わったら、待っていた窓は閉じ、DM は「✅ ログインが戻りました」になる
- `CLORD_LOGIN_RELAY=0` で、この節の動き（窓・リンク・コード受付）だけを止められる。切れの DM は残る

### 止まっていた窓は立ち上げ直さない

ログインし直せば、止まっていたスレッドの claude は**同じ窓のまま**次のメッセージから動く。2026-11-09 に本番で確かめた: 09:17 に窓 `@122` の claude がログイン切れで止まり、09:22 に別の場所で `/login` されたあと、09:23 のメッセージは同じ窓（`start_claude` 無し）に届き、ターンは正常に終わった。だから c-lord は窓を立ち上げ直さない。
