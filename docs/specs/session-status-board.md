# あるべき動き: 📊 Session Status ボード

> これは「あるべき動き」。理念 [`docs/PHILOSOPHY.md`](../PHILOSOPHY.md) の下位。迷ったら理念に照らす。
>
> 対象: `DISCORD_CHANNEL_ID` のチャンネルに出る `📊 Session Status` の embed。
> 関連: [thread-lamp.md](./thread-lamp.md)（スレッド名/リアクションのランプ）/ [turn-end-notification.md](./turn-end-notification.md)（ターン終了の呼び出し）。

## 既定ではオフ（#761）

**板は opt-in。** `CLORD_SESSION_STATUS_BOARD=1`（`true`/`yes`/`on` も可）を設定したときだけ出る。何も設定していない bot は:

- 起動しても再接続しても、**チャンネルに板を投稿も書き換えもしない**
- 前の起動が残した自分の板は**起動時に1回だけ片付ける**（下の #720 の掃除と同じ条件。`CLORD_DASHBOARD_SWEEP=0` なら残す）。誰も更新しなくなった板は「0s ago」のまま嘘をつき続けるから（#754）
- **ターン終了の呼び出し（スレッドに出る `🟡 Claude has finished … @投稿者`）は変わらず出る**。板と同じクラスが出しているが別の機能（#481）で、板をオフにしても消えない
- 各スレッドの `-# 🔄 C-lord を再起動しました…` の1行は**この設定と無関係**（#761 の対象外）

なぜ: 開発中は bot の再起動が1日に何回もあり、そのたびにチャンネルの表示が動いて騒がしかった。利用者が頼んでいない表示は既定で出さない（yousan 2026-09-16）。

以下は**板をオンにしたとき**の動き。

## これは何か

**「いまどのセッションが動いているか」をチャンネルで一目で見るための板**。スレッドごとに 🟢 Auto-processing / 🟡 Waiting for input と経過時間が並び、状態が変わるたびに**同じメッセージが書き換わる**。

board は**チャンネルに1枚だけ**。ピン留めされていて、📌 を開けば必ずそれが出る。

## あるべき動き（利用者から見て）

### ふだん

- チャンネルに `📊 Session Status` が **1枚**ある。動いているセッションが無いときは `No active sessions.`
- スレッドの状態が変わると、**その1枚が書き換わる**（新しいメッセージは増えない）
- 4時間動いていないスレッドの**行**は板から消える（板そのものは消えない）

### bot を再起動したとき

- **板は増えない。** 起動した bot は、チャンネルに既にある自分の板を**引き継いで書き換える**（#720）
- 前のプロセスが残した**死んだ板は起動時に削除される**。3回再起動しても、チャンネルにある板は1枚のまま
- 📌 を開くと**いま生きている板**が出る。ピンできなかったときは**ログに WARNING が1行残る**（ピンは Discord 側で1チャンネル50件が上限で、埋まると失敗する）

### 触らないもの

- 引き継ぎ・削除の対象は **3条件すべてを満たすメッセージだけ**: **この bot 自身が書いた** / embed のタイトルが `📊 Session Status` / いま生きている板ではない
- 他の bot（staging 等）の板、人の発言、別の embed は**一切触らない**

## 境界

- 板を探す範囲は**チャンネル末尾500件**と**ピン一覧**。ピン一覧も見るのは、📌 を占有している板が履歴の遥か奥にいることがあるため（#720 の本番では 2026-02-24 の板が4枚ピンされていた）
- 1回の起動で消す板は**最大400枚**。それを超える分は次の起動で消える（数千リクエストを一度に投げない）
- 削除に5回失敗したらその回の掃除はやめる（権限が無い、の意味なので粘らない）
- 掃除は**起動をブロックしない**（別タスクで走る）。板の引き継ぎ自体は起動時に同期で終わる
- 履歴もピンも読めない（権限が無い）ときは、**新しい板を1枚出して続行**する。起動は落とさない
- `CLORD_DASHBOARD_SWEEP=0` で**削除だけ**を止められる（引き継ぎは止まらない＝板が増えることはない）

## バグの例（こうなっていたらバグ）

- bot を再起動したら `📊 Session Status` が2枚になった（#720 以前の状態 — 本番で369枚、チャンネルの全メッセージの77%）
- 📌 を開くと、いま動いていない古い板が出る
- 板をオンにしているのに、板が1枚も無く、スレッドの状態が変わっても何も出ない
- 何も設定していないのに、起動でチャンネルに板が出る／書き換わる（#761 以前の状態）
- 板をオフにしたら、ターン終了の呼び出しまで来なくなった
- 他の bot が書いた板や、人の発言が消えた
- ピンに失敗しているのにログに何も出ない（DEBUG 止まり — #678 の規律違反）

## 根拠

- #67 — 板そのものの導入
- #481 / #495 / #583 — 🟡 に変わったときの呼び出し（誰を・どう呼ぶか）
- #632 / [turn-resilience.md](./turn-resilience.md) — 板の失敗はターンを巻き込まない（板は飾り）
- #678 — 「黙って捨てた」を DEBUG に落として済ませない。ピン失敗が DEBUG 止まりだったせいで、📌 が半年前の板を指していることに誰も気づけなかった
- #720 — 起動のたびに板が増えていた。引き継ぎ＋起動時の掃除はここで入った
- #761 — 板を opt-in にした（既定オフ）。再起動のたびにチャンネルが騒がしかったため
