# あるべき動き: ⏹ Stop ボタン

> 対象: ターン中にスレッドへ出る `-# ⏺ Session running (\`w1\`)` ＋ **⏹ Stop** ボタン。
> 関連: [turn-progress.md](./turn-progress.md)（進捗の1行）/ [session-close.md](./session-close.md)（`/workspace-stop` によるセッション停止）。

## これは何か

走っているターンを利用者が止めるための唯一のワンクリック導線。押すと `SIGINT`（Claude Code で Esc を押したのと同じ）が走行中のランナーへ届く。

**このボタンはプロセス内のランナーを直接握っている。** DB にも Discord にも「どのランナーか」は書かれていないので、**bot のプロセスが変わった瞬間、そのボタンは何も指していない**。ここが以下の規律の根拠になる。

## あるべき動き（利用者から見て）

### ターン中

- ターンが始まると、スレッドの末尾に `-# ⏺ Session running (\`w1\`)` と **⏹ Stop** が出る
- Claude のメッセージが増えるたびにボタンは**下へ付け直される**（古い方は消える）。スレッドに同時に存在する Stop ボタンは **1個だけ**
- 押すと、そのターンが止まり、ボタンは無効になって「停止しました」が出る

### ターンが終わったとき

- **ボタンのメッセージごと消える。** 押せないボタンをスレッドに残さない

### bot を再起動したとき

- **前のプロセスが残した ⏹ Stop ボタンは、起動時に消える（#634）。**
  シャットダウン中は aiohttp のセッションが先に閉じるため、終了処理からはメッセージを消せない（`StopView.disable: could not delete message — Session is closed`）。そこで**起動側が掃除する**。
- 掃除の対象は3条件すべてを満たすメッセージだけ: **この bot 自身が書いた** / 本文が `-# ⏺ Session running` で始まる / **コンポーネント（ボタン）が付いている**。他の bot のメッセージも、ボタンを剥がされた履歴行も触らない
- 対象は**この bot プロセスが起動する前に書かれたメッセージだけ**（#752）。起動後に書かれた Stop は生きているターンのものなので、掃除が走っている最中に始まったターンのボタンも消さない

## 境界

- 掃除はスレッド1件が読めなくても（削除済み・権限変更・アーカイブ）**他のスレッドを巻き添えにしない**。1件ずつ握りつぶして次へ進む
- **どこまで遡るか（#752）**: スレッドごとに「前回の掃除でどこまで読んだか」（`ui_sweep_cursors`）を覚えておき、**次の起動ではその続きから、前回以降のメッセージを全部読む**。初めて訪れるスレッドだけは末尾から最大 5,000 件まで遡る（本番 2026-09-23 実測: 363 スレッドの全履歴で、最も深い残骸は 1,667 件の下。全スレッドを底まで読んで 517 リクエスト — 1回きりのコスト）
  - かつては毎回「末尾100件 × 最近使った200スレッド」を読み直していたため、残骸が後続の発言に押し下げられると**永久に届かなくなっていた**（本番: 164 件の下に埋もれた 08-07 の Stop、1度も訪問されない 139 スレッド）
  - 前回以降に何も書かれていないスレッドは**履歴を1件も取得しない**（`last_message_id` がカーソル以下ならスキップ）
  - 消せなかった残骸があるときは、カーソルをその手前で止める。次の起動で**もう一度試す**（黙って読み飛ばさない）
- 訪問するスレッドは既定で**全件**（#752 以前は最近使った200件）。`CLORD_STOP_SWEEP_MAX` で上限を付けられる（`0` で無効）
- 消せなかったもの・読めなかったスレッドは **INFO ログ**にスレッド ID と件数つきで残る（`dead-button sweep: could not …` — #678/#752）
- 掃除は**起動をブロックしない**（別タスクで走る）

## バグの例（こうなっていたらバグ）

- bot を再起動したあと、スレッドに残った ⏹ Stop を押すと `This interaction failed` とだけ出る（#634 以前の状態）
- 1つのターンに ⏹ Stop が2個以上並んでいる
- ターンが終わったのに ⏹ Stop が残っている
- 走行中のターンの ⏹ Stop が、起動時の掃除で消えた
- 他の bot が書いたメッセージが消えた

## 根拠

- #91 — シャットダウン中の `RuntimeError("Session is closed")` を握りつぶす（ここでボタンが残る）
- #466 — ボタンの押下は allowlist で認可される（`AuthorizedViewMixin`）
- #634 — 起動時の掃除。本番で残骸が46件、いずれもシャットダウン時のログとして残っていた
- #752 — 掃除が末尾100件 × 200スレッドの窓しか見ておらず、窓の外の Stop が残り続けていた（本番 2026-09-23: 押せる見た目の Stop 65件、うち約17件は走行中のターンの正当なもの）。カーソル方式にして窓を無くした。同じ掃除で ❓ 質問メニューの残骸も外す（[ask-menu-lifecycle.md](./ask-menu-lifecycle.md)）
