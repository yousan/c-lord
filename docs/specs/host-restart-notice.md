# あるべき動き: ホスト再起動で作業途中の Claude が止まったとき

> これは「あるべき動き」。理念 [`docs/PHILOSOPHY.md`](../PHILOSOPHY.md) の下位。迷ったら理念に照らす。

## これは何か

c-lord **だけ**を再起動しても、Claude は tmux の中で動き続けます（#406）。
しかし**ホスト（WSL）ごと再起動**すると tmux も Claude も全部落ち、c-lord の終了処理も走りません。
作業の途中だったスレッドは「作業中のような見た目のまま」無言で止まります。

この spec は、そのとき **c-lord の起動時に、途中で止まったスレッドにだけ一文を出す** 動きを決めます。

## あるべき動き

### 正常時

- c-lord の起動時、**Claude が動いていない**スレッドのうち、**Claude Code 自身の会話記録（jsonl）の
  最後が「ターンの途中」**のものにだけ、次の一文が出る:

  > ⚠️ ホストの再起動で、作業の途中で Claude が止まりました。続けるなら、このスレに「続けて」と投稿してください。

- 一文のあとに「続けて」と投稿すると、**会話を覚えたまま**再開する（#700 の既存動作）
- 一文には**メンションもボタンも無い**。**自動では再開しない**（続けるかは人が決める — #406）

### 判定（何を「途中」とみなすか）

判定に使うのは **jsonl の最後の会話エントリだけ**（DB に状態を持たない）。末尾に付く記録用の行
（所要時間・添付・タイトル等）は会話ではないので飛ばす。

| 最後のエントリ | 判定 |
|---|---|
| Claude の返事で、返事を終えている（`end_turn`） | 待っていた → **出さない** |
| Claude の API エラー表示 | そこで止まって待っていた → **出さない** |
| Claude がツールを呼んだところ / ツールの結果 | 途中 → **出す** |
| 利用者の依頼（Claude がまだ答えていない） | 途中 → **出す** |
| `[Request interrupted by user…]`（利用者が Esc 等で自分で止めた） | **出さない** |
| スラッシュコマンドの記録（`/clear` 等） | ターンではない → **出さない** |

どの jsonl がそのスレッドのものかは、ミラーと同じ方法で決める（c-lord が名付けたセッション — #773）。

### 境界

- **Claude が生きているスレッド**（c-lord だけの再起動）→ 出さない。ターンの途中でも本当に作業中だから
- **tmux に問い合わせられない**（tmux が無い・権限エラー等）→ どのスレッドにも出さない。
  「分からない」を「止まった」と言い換えない（[fleet-tmux-restart.md](./fleet-tmux-restart.md) と同じ規律）。
  なお**tmux サーバが居ない**のは「分からない」ではなく「全員止まった」— ホスト再起動の直後はこれが普通
- **同じ停止について、何度 bot を再起動しても一文は 1 回だけ**。重複の判定も DB は使わず、スレッドそのものを見る:
  最後に誰か（人）が書いてから後に、この一文がもう出ていれば出さない。
  「続けて」→ 再開 → また途中で落ちた、なら新しい停止なので**もう一度出る**
- **停止済み（`/workspace-stop`）・削除済み・ロックされたスレッド**には出さない
- 自動アーカイブされただけのスレッドには出す（止まったことに気づいてほしいスレッドそのものなので）
- 作業ディレクトリを共有する複数スレッドでは、そのディレクトリの会話記録を持つスレッド（最後に使ったもの）にだけ出す（#719）

## バグの例

- ホスト再起動のあと、途中だったスレッドが「作業中の見た目のまま」何も出ない。**バグ**
- 返事を終えて待っていたスレッドにこの一文が出る。**バグ**（狼少年になる）
- c-lord だけ再起動したら、動いている Claude のスレッドにこの一文が出る。**バグ**
- bot を再起動するたびに同じ一文が積み重なる。**バグ**
- 一文にメンションやボタンが付く・勝手に「続けて」が送られる。**バグ**

## 根拠

- **#807** — 2026-09-25 22:47 のホスト再起動で本番の全 Claude が落ち、2026-09-28 まで誰も気づかなかった
  （このときは偶然どのスレも返事を終えていた）。yousan と合意（2026-09-28）: 判定は jsonl の最後のエントリだけ、
  DB に状態を持たない（DB で追うと実装後もバグが出続けるため）、メンション・ボタン・自動再開なし
- 実データ確認: 再起動直前 5 日間の transcript 528 本で「返事を終えた」と「途中」が最後のエントリで区別できた
- **#406** — 自動で「続けて」を送るのは意図しない前進になるので否定済み
- **#796** — 押せる見た目で押しても何も起きないボタンを作らない
