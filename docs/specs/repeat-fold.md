# あるべき動き: 同じ発言の繰り返しを1通にまとめる

> これは「あるべき動き」。理念 [`docs/PHILOSOPHY.md`](../PHILOSOPHY.md) の下位。迷ったら理念に照らす。

## これは何か

Claude が同じ短い発言（`待機中。` など）を何百回も繰り返すことがあります。
そのまま流すとスレッドが埋まり、本当に読むべき報告が見つからなくなります。
c-lord はその繰り返しを**1通のメッセージにまとめ、何回ぶんまとめたかをその1通の中で数え続けます**。

## あるべき動き

### 正常時

- ターンの途中で、**少し前に出したのと同じ文**がまた来ても、最初の **3回**（`REPEAT_FOLD_AFTER`）までは普通に出る
- 4回目からは新しいメッセージを作らない。代わりに1通だけ出して、それを書き換えていく:

  ```
  -# 🔁 同じ発言が続いています — 57 回ぶんをこのメッセージにまとめました: 「待機中。」
  ```

  何種類かの文が交互に繰り返されているときは、それぞれの回数も並ぶ（多い順に3種類まで）:

  ```
  -# 🔁 同じ発言が続いています — 12 回ぶんをこのメッセージにまとめました: 「待機します。」×6 · 「待機中です。」×3 · 「待機中。」×3
  ```

- **「直前と同じ」ではなく「少し前に出したどれかと同じ」で判定する。** 実際のループは
  `待機します。` → `待機中です。` → `待機します。` → `待機中。` … と交互で、
  「直前と同じ文」は1回も来なかった。直前比較ではこの 616 通を1通も減らせない
- **別の文が来たら、それは普通に出る**（まとめが後の発言を飲み込まない）。
  そのあとまた同じ繰り返しに戻ったら、その報告の下に**新しいまとめを1通**出して数え直す
  （報告がまとめの上下に挟まれて順番が狂わないように）。一度ループと分かったターンでは、戻ったときにもう一度3回ぶん流すことはしない
- まとめた事実は bot ログに **INFO** で残る（`thread=<id>` 付き、何をどれだけまとめたか）

### 境界

- **ターンの最後の返事（通知が飛ぶ返事）はまとめない。** 繰り返しと同じ文でも、返事として普通に出る。
  返事は利用者が「ターンが終わった」と知る手段なので、上の方のまとめに吸い込まれると困る
- **まとめはターンをまたがない。** ターンが終わる／人が新しく書き込むと、覚えていた文は忘れる
- 同じ文が時々出るだけ（間に別の文が挟まる）なら、まとめない。
  例: `CI を待ちます。` → `テスト 3 件目が通りました。` → `CI を待ちます。` … は3回を超えても普通に出る
- まとめに引用する文は1行・40文字までに縮める
- 書き換えは5秒に1回まで（Discord の編集回数の上限に当たらないように）。繰り返しが終わった時点で最終の回数に必ず書き換わる
- `CLORD_MIRROR_VERBOSITY=full`（デバッグ用に全部出すモード）ではまとめない

### エラー時

- まとめの1通が投稿できなかった／書き換えられなかったときも、**繰り返しは流さない**（同じ文はすでにスレッドにある）。
  何回まとめたかは bot ログに残る
- 書き換えができない構成では、まとめの1通は回数を書かない
  （`以降はこのメッセージにまとめます`）。古くなる数字を出さないため

## バグの例

- 同じ1行が延々続いて、スレッドに数百通並ぶ → **バグ**（#747）
- 交互に繰り返される数種類の文がまとまらない → **バグ**（#747。実際のループはこの形だった）
- 繰り返しのあとに来た本当の報告が出ない → **バグ**（まとめすぎ）
- ターンの最後の返事がまとめに吸い込まれて届かない → **バグ**
- まとめた事実が DEBUG にしか残らない → **バグ**（#678）

## 根拠

- **#747** — 2026-09-15、1本のスレッドが16分29秒で同じ3文を **616 通**受け取り、そのターンの本当の投稿 12 通が埋もれた。
  同じ形が同じ週に5スレッド（616 / 256 / 239 / 106 / 66 通）。transcript を数えると c-lord の重複投稿ではなく、
  Claude 側のループを 1:1 で写していた。当時の transcript で試算すると、ループの文は
  616→5 / 259→17 / 242→9 / 114→7 / 78→9 通になり、それ以外の投稿は1通も減らない
- **#678** — 捨てた事実は INFO に残す。黙って捨てるのでも洪水にするのでもなく、1行の事実として出す
- **#539** — 同じく「1通を書き換えて伝える」[ターン中の進捗表示](./turn-progress.md)。まとめの1通が出るときは進捗表示を下に残さない
